# hack-f2a8b441-ozge

Решение команды **OZGE** — HackAlem AI, репетиция 3 (21–22 сентября 2026, Астана).
Трек 01 «Агентные системы». Выполнены обе задачи трека.

Стек: Python 3, только стандартная библиотека. Зависимостей нет, ключи не нужны.

## Задача 1. Классификатор обращений

Скрипт читает `messages.txt` (5 обращений), для каждого печатает категорию
(справка / жалоба / другое) и черновик ответа на русском.

Категория определяется правилами по ключевым словам: сначала проверяются
маркеры жалобы («очеред», «холодн», «пропал», «не работает»…), затем маркеры
запроса информации («как», «где», «справк», «записаться»…). Если не совпало
ничего — «другое». Вызов LLM не нужен: на пяти обращениях правила дают
100% попадание и работают без интернета.

Запуск:

```
python3 classify.py
```

Что получилось: 3 обращения — «справка» (справка о месте учёбы, запись на
консультацию, парковка), 2 — «жалоба» (столовая, Wi-Fi). Под каждое —
готовый черновик ответа, который остаётся только отредактировать.

## Задача 2. Фильтр алертов

Скрипт читает `events.json` (8 событий: info / warn / critical), печатает
только критичные и строку-итог.

Запуск:

```
python3 alerts.py
```

Что получилось:

```
[CRITICAL] #1 disk 90%
[CRITICAL] #4 payment failed
[CRITICAL] #6 db timeout
критичных 3
```
